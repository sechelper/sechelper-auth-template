# 0003 配置中心与业务配置提供者

## 状态

已采用。

## 决策

框架增加配置中心模块。配置以大写环境变量名作为 key，value 使用现有 Session AES-GCM 密钥加密存储在 PostgreSQL。管理端只展示元数据，敏感值不可回读；写入和删除受独立的 `configuration:write` 权限保护并写入安全审计。

业务模块不直接依赖配置中心的数据库、HTTP Handler 或环境变量。宿主通过 `application.ConfigurationProvider` 注入只读接口，业务使用 `Get(context.Context, key)` 读取已解密值。这样保持业务模块可测试、避免配置存储反向耦合业务，同时允许不同业务使用自己的 key 命名空间。

数据库连接是配置中心的 bootstrap 依赖。配置中心值可被业务模块运行时读取；需要重建数据库、Redis 或其他基础设施客户端的值，统一在下一次进程启动时生效。生产环境仍必须通过部署密钥或显式启动配置提供初始数据库连接与加密密钥。

## 回滚

代码回滚保留 `configuration_entries` 表和新增迁移，不回滚或修改已应用迁移。若暂时停用配置中心，可移除管理端路由和模块装配；历史业务配置仍保留，恢复模块后继续可读。
