# ADR 0003：管理后台设置入口跳转统一身份中心

## 状态

已采用。

## 背景

管理后台账号菜单需要提供“设置”入口，打开统一身份中心。身份中心地址随部署环境变化，不能写入前端源码常量。

## 决策

- 管理后台从 `globalThis.__APP_CONFIG__.identitySettingsUrl` 读取统一身份中心完整入口地址。
- 部署环境负责注入该运行时配置；前端不推导地址，也不提供硬编码兜底。
- 仅接受 HTTPS 且不含 URL 用户名或密码的地址。未配置或校验失败时保留菜单并显示配置错误，不执行跳转。
- 账号菜单将“刷新会话”替换为“设置”；“退出”行为保持不变。

## 影响

各环境需要在现有前端运行时配置注入环节设置 `identitySettingsUrl`，其值可以包含身份中心要求的具体页面路径。未配置时，用户会看到明确提示，其他管理后台功能不受影响。

## 回滚

恢复账号菜单中的“刷新会话”操作，并移除运行时配置读取、校验及本 ADR。部署侧可以同时停止注入 `identitySettingsUrl`。
